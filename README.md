# Masters-Thesis
This repository contains the data cleaning and analysis code for my master's thesis titled: _Interactive effects of adverse childhood experiences, sport participation, and sex on anxiety and depression_.

My master's thesis at UTSA was on the interactive effects of adverse childhood experiences (ACEs), sport participation, and sec on anxiety and depression. To test this interaction, I used four years of data from the National Survey of Children's Health (NSCH, 2016-2019). This repository includes data cleaning and analysis in R.
